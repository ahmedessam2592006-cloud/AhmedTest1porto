Firebase Settings

To use this admin panel for multiple clients with the same Firebase project, create separate documents in each collection. Each client gets their own portfolio page that reads from their specific document. For separate Firebase projects, update the config in js/firebase-config.js.

Database Structure

projects/ { document }
  - title: string
  - category: string
  - description: string
  - image: string (URL)
  - gallery: array (URLs)
  - year: string
  - client: string
  - createdAt: timestamp

videos/ { document }
  - title: string
  - youtubeId: string
  - description: string
  - createdAt: timestamp

settings/social { document }
  - instagram, behance, dribbble, linkedin, twitter, youtube: string
  - email: string
